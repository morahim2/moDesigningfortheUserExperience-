# moDesigningfortheUserExperience- 
Project Summary
Designed for consumers to explore, purchase, and sell items in a safe and user-friendly environment, BidBuy Marketplace is a responsive, single-page website. Built with semantic HTML5, Bootstrap 5, and JavaScript, it offers an organised layout with seamless navigation, weather integration, and visually appealing areas for product categories.

User Narratives
From a user's perspective:
I wish to simply look through product categories to rapidly locate what I require.
I would like a mobile-friendly experience to allow me to shop on the go.
I want to see pertinent data like weather to guide my outdoor-related buying choices.
I wish to reach the site administrators via a straightforward form.
Development Method
Wireframe Improvement
Design best practices guided our changes to the original wireframes:
Included carousel features on the front page.
Added simplified labels and iconography to facilitate navigation.
Simplified smartphone design for thumb-friendly access.

Test Scenarios:
Navigation: Click every nav menu link; make sure it scrolls to the right area.
Responsive Design: Test on mobile view and resize the window.
Weather API: Make sure weather data loaded when API key is entered.
Form of Contact: Fill out and submit; verify placeholder operation (no backend).
Bugs Discovered and Fixed:
Weather not loading was addressed by changing the API call format.
Bug: Text overflow in category cards fixed using Bootstrap utility classes.
Current Problems:
Form doesn't transmit data since no backend is set.
